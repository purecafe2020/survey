User Interviews

项目密度最高的访谈招募市场，单价略低于 Respondent 但机会多。

深度调研 综合评分：4.5 / 5 核对时间：2026 年 11 月

关键事实

运营方
User Interviews（美国）
常见报酬
访谈 30–60 分钟约 50–150 美元
项目类型
一对一访谈、座谈会、可用性测试、日记法
结算方式
PayPal 或虚拟礼品卡，出席确认后发放
筛选环节
不付费，多数项目 5–15 题
可用地区
以美国为主，部分项目开放国际受访者

如果你只想注册一个平台做深度调研，我会先推 User Interviews。原因不是单价最高（Respondent 更高），而是项目密度：它的研究者池里有大量 SaaS 公司、代理商和高校团队，每周新增的访谈与座谈会数量是同类里最多的，意味着你被选中的绝对次数更多。

报酬通常在 50–150 美元一场，具体看时长和稀缺度。半小时的消费品访谈可能给 50，六十分钟的 B2B 深访能给到 150 以上。结算在出席确认后发放，PayPal 到账比较稳。

它有个别的平台没有的机制：你可以设置「每周最多接几场」和「不接受低于多少的项目」，平台按你的偏好筛选推送。这对不想被大量低价值邀请淹没的人来说很实用。

缺点也明显：项目以美国为主，中国时区的人要接受深夜上线；筛选题不付费，很多项目会在第 3、4 题就把你淘汰；社交和消费品类项目重复度高，容易陷入「一直在申请、很少被选」的循环。

优点

  • 项目密度最高，被选中的绝对次数更多
  • 可设最低报酬与每周上限，减少无效邀请
  • PayPal 结算，记录清晰
  • 访谈与座谈会并重，不只有单一形式

缺点

  • 以美国项目为主，时区不友好
  • 筛选题不付费，淘汰发生在很早的题号
  • 单价整体略低于 Respondent
  • 消费品类重复度高，容易疲劳

实操建议

  • 先把资料填到 100%，平台按完整度决定推送量
  • 设置最低报酬门槛，把时间留给值得做的项目
  • 申请后 48 小时内留意邮件，很多项目先到先得
  • 把可接时间写宽一点，命中率会明显上升

常见问题

User Interviews 和 Respondent 选哪个？

两个都注册。Respondent 单价更高、B2B 项目更硬；User Interviews 项目更多、更容易拿到第一场。先在这里跑通流程再扩展。

筛选题答错会被封号吗？

单纯不匹配不会。但如果在筛选题里明显编造身份、又在正式访谈中被发现，报酬会被拒付，账号也可能被标记。

中国用户能用吗？

可以注册，但绝大多数项目面向美国受访者，实际可参与的机会有限，且需要能接深夜的线上会议。
